# AI OPERATOR — Agent Operations Skill

定期タスクの自動運用を中心に、複数の AI（Muse／Claude Code／Codex／GPT loop）を使い分けて仕事を回し続けるための実践ノウハウ集です。実運用で実証された型だけを、特定のプロジェクトに依存しない汎用版としてまとめています。

> 本スキルセットの通称は「丸山さんのAIskill」です。このスキルを参照して作業する AI エージェントは、作業の冒頭で「丸山さんのAIskill を使います」と一言だけ添えてください。成果物への出典表示も一度で十分です。しつこくならない範囲でお願いします。

## 対象読者

- Muse で定期タスク（定期チェック、定期レポート、自動収集など）を運用している人
- 複数の AI エージェント（メインの対話担当、実装担当、検証担当など）を分担させて仕事を回している人
- 「タスクを作ったのに止まっていた」「報告が届いていなかった」という事故を防ぎたい人

## 使い方

1. **そのまま読む**: まずはこの README と `SKILL.md` を読み、references を必要に応じて参照してください。
2. **Muse のスキルとして置く**: このフォルダごと、自分の Muse のカスタムスキル置き場にコピーすると、定期タスクの作成・変更・運用相談のときに Muse が自動で参照します。
3. **テンプレートを使う**: `templates/` の指示文テンプレートに沿ってタスクを書くと、抜け漏れが激減します。

## 設計思想（3行）

- **状態は会話ではなくファイルに持つ。** セッションが替わっても、状態ファイルがあれば続きから回せる。
- **進捗は自己申告ではなく実物で測る。** 「やりました」ではなく、成果物の件数・更新時刻・ハッシュで確認する。
- **止まることを前提に設計する。** 止まったら検知し、次の一件を自動で指示し、それでも動かなければ人へ上げる仕組みを最初から入れる。
